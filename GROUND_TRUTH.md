# Ground truth

Generated by `tools/HistoryGenerator`. Commit numbers are 1-based positions in
`git rev-list --reverse --first-parent 8b937a7..master` (topological order; never order by date).
Targets: `linux-x64`, `linux-arm64`, `windows-x64`, `macos-arm64`.

Machine-readable files: `events.json` (atomic events with tiers and windows), `segments.jsonl`,
`expected-durations.csv` (model + realized seeded draws for attempt 1), `commits.json`, `scenarios.json`,
`bad-runners.json`, `negative-series.json`.

Tiers: `must` (a competent detector should find it), `should`, `optional` (at or below the noise floor),
`must_not` (no change happened for this test/target; any alert is a false positive).

Measurement notes:

- Model values exclude harness overhead. Measured durations are typically 0-2 ms above the model, and every
  simulated call has about 3% multiplicative jitter.
- Tests that start in the first parallel batch of a test run (the first ~2 tests of each project) can be 1-4 ms
  slower because of start-up contention. Which tests start first varies from run to run; it is not a change.
- `cpu×N` (real CPU work) has no absolute value; only the ratio between segments is part of the ground truth.
  Its duration also depends on the runner's CPU (`cpu_model` column), which differs between runs; dividing by
  `CatalogHasherTests.Hashes_catalog_export` from the same run removes most of that.
- Seeded draws (uniform, mixture, tail) are exact per run: `expected-durations.csv` has the realized value for run
  attempt 1, including the noisy-machine factor from `bad-runners.json`.
